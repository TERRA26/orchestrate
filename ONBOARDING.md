### Skills to Know About

- /model — Switch between Claude models mid-session (e.g. `claude-opus-4-6`). Used heavily to pick the right model for the job.
- /compact — Compress conversation context when a session gets long. Keeps you from running out of context on big tasks.
- superpowers (plugin) — Adds 15 workflow skills: brainstorming, TDD, debugging, planning, code review, git worktrees, and more. Installed and active.
- frontend-design (plugin) — Guides building production-grade web interfaces. Installed and active.

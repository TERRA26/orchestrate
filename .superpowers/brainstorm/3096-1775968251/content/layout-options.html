A: Orchestrator Rail + Agent Panels

Orchestrator lives in a narrow left rail (like today's panel). Agent threads fill the main area side-by-side. You talk to the orchestrator in the rail, agents stream in the panels.

B: Orchestrator Top Bar + Agent Grid

Orchestrator occupies a compact top strip with status chips and a command input. Agent panels fill the rest in a responsive grid. Scales to 2-4+ agents.

C: Equal Threads Side-by-Side

Orchestrator is a full chat thread (left), agent panels sit next to it as equal-sized panes. Each panel has its own composer for direct access (option B interaction). Extends the existing split-view pattern to N panes.

Consider: the orchestrator currently lives as a right-side panel. These options rethink that for multi-agent mode.
